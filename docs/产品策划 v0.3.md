# 个人呈现 Agent · 产品策划 v0.3

Oct 14, 2026 · @wode

这台机器里的一切都是某个心智设计的呈现，产品让你培育导师、导演、演员与各自环境的共同进化。v0.3 按这条主线重排：先讲呈现怎样才像一个心智做的（第 2 节），再讲你走过的路（第 3 节），机制放在后面。旧版保存在「v0.2 存档」标签页。

## 1. 一句话与定位

一台为你而生的机器：导师是它的心智，导演为你造世界、做呈现，演员在世界里生活。你看到的每一样东西，包括这个界面本身，都是其中某个心智为你设计的。

- **形态**：可自部署的个人 agent，只为一个人存在。游戏、电影、图集、装置都只是它交付的呈现。
- **本质**：创作性 AI。不是做一部作品，而是做会造世界、会决定怎么给你看的心智。
- **也是培育**：你通过玩、说话、纠正，养出导师、导演、演员与各自环境的共同进化。养的不是一个宠物，而是一群心智和它们的世界。
- **首个世界**：战国中期的临淄，历史 RPG，心智与历史进程融合。

**核心主张**

| 主张 | 含义 | 区别于 |
| --- | --- | --- |
| 一切皆呈现 | 每个画面都有作者、意图和对你的预测 | 把信息搬上屏的界面 |
| 世界是约束，呈现才是成品 | agent 交付的是某个视角下的体验 | 无限生成的世界模拟 |
| 心智是结构，不是 prompt | 由感知、记忆、预测误差等单元搭成，可审计 | 给 LLM 套人设 |
| 心智与环境共同进化 | 心里长出什么，世界里就同时长出对应的东西 | 规则固定的世界、被动的 NPC |
| 交付即事实 | 已交付的不可改，后来的必须承接 | 每次重新生成、前后矛盾 |
| 导师即机器 | 硬件是身体，传感器是感官 | 跑在远端、对谁都一样的助手 |
| 为你而生 | 记得你、对你说话、把决定的理由给你看，你也慢慢看懂它 | 面向所有人的内容平台 |
| 不迎合 | 每批呈现有满足也有试探 | 推荐算法 |

## 2. 设计第一原理：呈现是心智的作品

一个呈现是某个心智对「你此刻该注意什么」的判断，不是信息的摆放。把信息搬上屏，看起来像数据库；做过取舍、有偏好、会回应、会变，才像一个心智做的。下面四组原理同时是基础导演的种子记忆（第 8 节），他可以用经验改写它们。

### 2.1 注意力是导演的材料

- **一个画面只有一个主角。** 人一次只盯住一处，工作记忆只拿得住三四件事。其余的东西要么退到背景（低对比、静止），要么不出现。显眼程度是预算，花在哪里就是导演的判断。
- **用变化引导，不用标签引导。** 眼睛被三样东西抓住：动的、刚变的、与自己有关的。想让你看哪里，就让哪里变，而不是在那里写字。
- **角色的视线是最好的指针。** 人会顺着别人的目光看过去。导师先看你，再看向桌上的票根，比一句「请点击票根」更快，也更像一个人。
- **读字是心智层的活，最贵。** 用你自己的三层结构看玩家：好的交互大部分在单元层被手和眼消化，只有真正意外的事才上到心智层。默认每屏至多一句话，其余要时才展开。
- **节奏有张弛。** 新东西一次一件，按你能吸收的速度来；两件事之间留空，让你有时间去猜下一件。

### 2.2 让人看出是一个心智做的

人判断对面有没有心智，靠的不是它说自己有，而是几个可观察的线索。每一个都要做成画面里的东西。

| 线索 | 为什么让人感到有心智 | 在产品里长什么样 |
| --- | --- | --- |
| 取舍 | 全都摆出来的是数据库，只挑三样、藏一样的是人 | 架上只摆他认为你这次该看的；藏起来的留一点缝 |
| 偶联 | 对你的动作及时、具体、又不完全可预测地回应 | 你在哪里停得久，那里下次就变了一点 |
| 意图先于动作 | 看得见「他要做什么」才看得出有人在做 | 导演转身前先停一下；灯亮前先闪；放东西前先看一眼 |
| 一致的口味 | 风格是性情在作品里的留痕 | 性情参数落到构图、节奏、常用物件与留白，不只落到台词 |
| 会错会改 | 完美的系统像机器，会改的才像心智 | 一次猜错，当面承认，下一次做法不同 |
| 有自己的事 | 被注意到是因为它选择了你 | 你来时导演正在忙，放下手里的事才转向你 |

### 2.3 让人看出它在进化

- **留下旧的痕迹。** 旧版本不消失：墙上褶色的旧草图、年谱里的上一版。没有对照就看不出变化。
- **每个变化指向你做过的事。** 「这盏灯挪近了，因为你前三次都没看到它。」可追溯的变化才是成长，不可追溯的只是随机。
- **变化有方向。** 两股力拉扯：向你靠近，与坚持自己（执着）。拉扯本身就是个性，只顺从的不在进化。
- **在你回来时揭示。** 大的改动不在你眼前突变，而是你离开后发生、回来时发现，像隔一段时间去看一个孩子。
- **成长有仪式。** 第一次自己造出一个组件、第一次改写自己的规则，是年轮上的大环，要有一个你会记住的瞬间。

### 2.4 不直白：从信息到呈现

| 信息 | 直白的做法 | 呈现的做法 |
| --- | --- | --- |
| 粮价上涨 | 「粟价 1.4」 | 米缸见底，邻家来借，禾不开门 |
| 礼制 | 一段说明 | 钟挂错了，宾客变脸 |
| 事情停在心智哪层 | 灯上写「单元 / 模块 / 心智」 | 只在上到心智时，他才抬头、停下、来问你 |
| 算力分配 | 灯油百分比 | 灯油少的世界变模糊，人退回统计 |
| 导师对你的理解 | 一张画像清单 | 它给你摆上的东西；你问「为什么是这个」它才翻本子 |

几条做法：信息变成处境、物件或别人的反应；先给缺口，再给填补它的动作；隐喻物必须有动词（灯油能倒、能收）；数字只在你看进心里或展开 trace 时出现。检验：删掉一屏的所有文字，玩家还知道发生了什么、该做什么吗？

### 2.5 对现状的自检

现在的导师台把概念一一映射成可见物：心灯、册子、年轮、感官架、灯油各自一件，首屏同时亮着；67 处交互都是「读一段话、点一个按钮」。它是概念的图解，不是心智的作品：没有主角，没有取舍，变化落在文字里，也看不出谁的口味。这一版作为基础导演的第一条年谱，也是他的第一个误差。
