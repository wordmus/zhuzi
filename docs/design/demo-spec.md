# 《推门 · 旱》试玩版 · 体验规格（给所有实现者的唯一依据）

依据：`docs/策划文档v0.2 存档.md` 第 2、4、5、9、11、12、19 节（主），`docs/presentation-pipeline-brief (2).md`（管线与 bench），`docs/notes/`（东周实验室 v1–v8、note6 心智定稿、note8/9 设想）。
目标：**眼前一亮，进入心流。** 推门 30 秒内开始玩；不读任何说明，能说出「我在帮禾想办法」；玩完想问「禾后来怎么样了」。

旧导师台的病（看 `scratchpad/old-desk/shots`）：十样东西同时抢注意、底部对话框加一排按钮、百分比与压力数字。**本作反过来：全屏一个场景、一个焦点、没有按钮、每屏最多一句话、没有数字面板。**

---

## 一、总原则（违反即返工）

1. **一屏一个焦点**：只有焦点明显地动；背景只有缓慢、低对比的呼吸（灯焰、热气、风里的草）。进入一个场景的前 3 秒，只有一个能做的事。
2. **字最贵**：每屏 ≤ 1 句（≤ 30 字，最好 ≤ 18 字）。没有说明文字、没有标签、没有按钮文字。信息放在物件的样子里：粟瓮的高低、孩子的姿势、田缝的宽窄、灯的明暗。
3. **每个动作 100ms 内有看得见的反馈**（光、形变、声音），1 秒内有意义上的回应。
4. **心智先从行为里读出来**：一件事停在单元层，禾手上的活没停；停在模块层，他停下看一眼田、换个做法；到了心智层，他直起身望天，开口说话。心象（看进心里）是第二层，给想看的人。
5. **取舍可见、不全说**：理由可以追问（悬停、长按），但不主动摊开。
6. **不变里的变**：地标不动（你的座位、导师的位置、门）；变化在你面前发生，或由角色的视线指过去。
7. **一镜到底**：门 → 屋里 → 桌上票根 → 票根化成点 → 临淄 → 东郊显影 → 禾。中间不黑屏、不切场景、不加载。
8. **语气**：少警句，允许插科打诨而不离题；禾对天意的理解可以又歪又合理（「天老爷，你是忘了东郊，还是忘了我？」）。

## 二、材质与风格（L1：程序化 2D，canvas）

**母题：楚/齐漆画。** 黑漆底、朱砂与赭石的平涂人物剪影（侧面、长衣、发髻/冠）、细金线的云纹边饰、青铜器纹样（菱纹、蟠螭）作边框。夜是黑漆，昼是帛（绢）。不是水墨，不是皮影，不是扁平插画。

| 色 | 值 | 来自 |
|---|---|---|
| 漆黑 lacquer | `#120d0b` | 漆器底色（夜、屋内） |
| 漆褐 lacquer-2 | `#2a1a13` | 漆器的暖黑 |
| 朱 cinnabar | `#b33a26` | 朱砂：田伯、印、票根边、灯焰芯 |
| 赭 ochre | `#b0763a` | 赭石：禾的衣、土 |
| 金 gold | `#c9a24a` | 金银错的线：云纹、灯 |
| 帛 silk | `#e7d9b6` | 帛画的底（白昼） |
| 帛暗 silk-dim | `#cbb98f` | 帛的阴影 |
| 黄土 loess | `#b99568` | 东郊的地 |
| 裂 umber | `#3b2a1e` | 田缝 |
| 青铜 bronze | `#4f6b5a` | 铜绿：铺首、铜镜、灯树 |
| 夜蓝 night | `#141826` | 夜空 |
| 粟 millet | `#d6b25a` | 粟、灯光 |

- **质感统一**（看起来精致的最便宜来源）：所有画面过同一层后处理——细颗粒噪点（帛纹/漆面）、轻微暗角、暖色光晕（加法混合）。由 `components/paint` 统一提供。
- **人物**：漆画式侧面剪影，比例修长；头小、衣长、袖宽；用 3–6 个贝塞尔形状拼成，关节可转（头、躯干、手臂、腿在衣下摆动）。禾：赭衣、短褐、发髻；田伯：朱衣、冠、宽袖；导师：漆褐深衣、坐在矮案后执笔；桑（妻）：赭红，挽髻；小石（子）：小、短衣；季：青衣、高冠、持简。
- **字体**：说话用 Noto Serif SC（回退 Songti SC）；「旱」字与印用画出来的篆意字形（SVG/路径），不依赖字体。
- **光**：夜里的一切亮处都是暖光（灯、窗），有缓慢闪烁；白昼的旱是白热的帛色，太阳是一枚朱红漆圆。

## 三、第一次来访（逐秒）

| 时间 | 你看到、听到 | 你做 | 实现要点 |
|---|---|---|---|
| 0–5 秒 | 黑漆夜空、金线云纹；夯土墙上一扇木门，门上铜铺首；墙上小窗里一点灯在动（唯一在动的东西）。蟋蟀、风。夜空里有一颗暗红的星挨着心宿（荧惑守心，几乎没人注意）。 | 推门（点/回车） | 首个可操作元素 ≤ 1 秒出现；悬停门：门缝透出暖光、木头轻响 |
| 5–15 秒 | 门向里开，镜头推进。屋里很暗。远处一棵青铜连盏灯，灯**一盏盏亮到你这边**（每盏一声编钟，五声上行）。导师坐在矮案后，正写完手上那一笔（笔画在纸上走完），搁笔，抬头看你，只说一句（方案里的 greet）。其余都暗着。 | 看 | 导师的写字是「连续」：你进门时他已经在写 |
| 15–25 秒 | 他把一张票根推过桌面，停在你面前：帛条、朱边，上面一个画出来的「旱」字。 | 拿起票根（点或往上拖） | 票根悬停微微抬起；拿起时有纸声 |
| 25–40 秒 | 票根飘起、散成一团金色的点；点落下铺成临淄（城墙是点的密处，淄水是流动的点带，东郊是稀疏的田格）。视线（鼠标/手指）所到之处，点微微聚拢成细节。**东郊有一片在呼吸。** 你看向东郊（停留 ≥ 0.8 秒或点击），那里**显影**：点凝成土、田、一个人——禾跪在一道田缝前。 | 看向东郊 | 显影像照片在药水里浮出来，从你视线处向外扩 |
| 40–90 秒 | 白热的帛色天、裂开的黄土、枯黄的粟。禾跪着，手按在田缝边。两件事可做：**碰田缝**、**望天**（往上看/点天）。碰田缝：禾的手顺着缝摸，土屑落下（单元层：手上活没停）。望天：镜头上摇，太阳一枚朱红圆；禾直起身望天（心智层），说：「天老爷，你是忘了东郊，还是忘了我？」 | 碰 / 望 | 然后禾想到家里的粟瓮和田伯——心象第一次自己打开 |
| 一局 8–12 分钟 | 禾的四季（见第四节） | 预演、行动、承诺 | 峰值：田伯开门；结尾：一个不可逆的承诺 |
| 回到咖啡厅 | 票根从东郊飘回来，落回桌上；导师在它上面**盖一方朱印**（印声）。说一句禾做了什么（结局的 mentorLine），**这才问「怎么称呼你？」** | 写名字，或不说 | 输入框是一条帛，回车即可；「不说」是把笔放下 |
| 离开 | 导师最后一句：「季那边，听说也有人敲门。」门在你身后，门缝透光。 | 关门 | 关门后：夜，窗里的灯还在动；桌上那张盖了印的票根留在画面一角 |

**第二次来访**（本机存储里有上一次）：咖啡厅几乎一样，你的座位还在原处；**一盏灯挪到了你手边**，导师的视线在它上面停了一下（基础导演：你上次没看它）；导师说结局的 echo（「禾到莒了，你走后第三天。」天数由真实流逝换算）；桌上多了一捆竹简（季的视角，毛坯，未盖印）；叔衡的话（经导师转述）：「叔衡说，你在田伯门口停了很久。」（由上次真实的停留算出，停得最久的地方）。墙角钉着导师台第一天的草图（年谱）。

## 四、核心玩法：住进禾的心，替他设想田伯

### 4.1 东郊是一卷横幅
像包山楚墓漆奁上的出行图：一条横向的画带，从左到右：**家**（茅屋、粟瓮）· **田**（田缝）· **井**（桔槔、乡邻、流言）· **社树**（老树；压力够了会长出社坛）· **田伯家**（高墙、门楼、铺首）· **路口**（往莒的路，柳）。镜头沿横幅平移，不跑图：**走一步就是一个决定，一天一步。**

季节由画带的色调与左上角的**四季转盘**（青铜圆盘，指针走）表示；没有日期数字。

### 4.2 每一天
1. 清晨：家里的样子先说话（粟瓮的高低、孩子在不在玩、母亲是否躺着）。有事件就发生（流言、天象、征粮）。
2. 禾的意向：他**朝某个地方看**，那条路微微亮——这是「他自己会做的事」，也是你此刻唯一的焦点。
3. 你可以：
   - **点那个亮着的地方**：同意，他去。
   - **点另一个地方**：建议他去别处。他可能照做（按自己的方式），也可能拒绝并说一句又歪又合理的话——被挡下的念头**留在他心里成为种子**。
   - **点禾**：看进他心里（心象）。
4. 禾走过去（2–3 秒），那里的事演出来（一两句话、一个物件的变化），世界回应，误差在行为上显出来。

### 4.3 心象：一面青铜镜里的一块田
点禾，他头顶浮起一面铜镜（蟠螭纹镜缘，铜绿），镜里是黄昏的一小块田——**禾的心**。里面有：
- **念头是种子**：亮的是正在想的，暗的是被挡下的（种子）。可以从流言里把一句话拖进来，变成一颗种子；也可以写一句话放进去（真的去想：模型把你的话翻译成禾能做的事，做不到的成为种子）。
- **小田伯**：田埂上站着一个陶俑一样的小田伯，手里一杆小秤，三个砝码：**情**（一只握着的手）、**利**（一袋粟）、**名**（一圈人）。砝码的轻重是**禾以为**田伯在乎什么。你可以拖动砝码（改他心里的小田伯）。
- **预演**：把一个来由（提旧情 / 押地 / 带乡邻）放到小田伯面前，小田伯按禾的信念做出反应（摆手、点头、伸手要地契），并说一句禾想象中的话。预演不花一天——**设想比走路便宜**。
- **三盏心灯**只在这里出现：单元、模块、心智；一件事停在哪层，哪盏亮。

### 4.4 峰值：叩门
禾带着一个来由去田伯家。叩门是你的手：**点铺首的环三下**（三声沉沉的木响，回声）。等——门缝里的光先出来——门开，田伯的脸。**这个停顿就是田伯在想**（若有模型，就是真的在想，话旁标「真的去想 · 秒数」）。
田伯的回应（给粟 / 借粟要还两倍 / 要买地 / 关门）来自**他自己的心智**（种子决定的真实权重 + 他此刻的处境：仓、王的征粮、门口有没有人看着）。
回到心象：小田伯与真田伯的差看得见——秤上的砝码滑到新位置，旧位置留一道淡痕（改稿留痕）。**小田伯随之变准。**

### 4.5 压力与成对生长
没下的雨、借不到的粮、孩子的饿，累积成压力。压力够了、而禾心里有「社」「天」的种子时：**社树下长出社坛**（土台隆起、立杆、彩缯），禾心里同时多出「祭」——二者一起记入事实账本（成对生长）。鬼神只作用于信念，不进入世界规则：祭社不会下雨，但会把乡邻聚起来——而田伯在乎不在乎「名」，决定了这群人对他有没有分量。

### 4.6 收束：不可逆的承诺
四季内任一承诺成立即收束：
- **借粮立券**：田伯肯借 → 一枚竹券，你亲手**掰成两半**（各执一半）。明年要还两倍。
- **卖地**：田伯要买地 → 禾抓起一把自己的土，放进田伯的手里。
- **投亲**：去莒 → 天亮前，一家人的剪影走上往莒的路，屋门开着。
- **祭社**：社坛已立 → 禾把来年的种粟献上，乡邻聚来；（若田伯重「名」，他开仓施粥）。
- **熬**：冬尽仍未决，禾自己决定（按他自己的意愿最高者）。
结尾停在一个画面上，不出结局名、不打分。票根飘回咖啡厅。

### 4.8 角色与环境共同进化（AGENTS.md 第 2 条：强张力、角色极强能动性）

**禾不等你。** 你是他心里的一个声音，不是遥控器。
- 每天清晨他先朝一个地方看（意向）。你 **6 秒**不动，他就自己去（拍 `self`）；他心里的意愿远高于你建议的那个时，他也会自己去，顺手留下一句又歪又合理的话。
- 他对环境**动手**：跪下摸缝、挑水浇苗、刨土、捡橡子、钉自家的门板、抓一把土。动作是主语，台词是附注。
- 他走得最多的那条路会被踩深；踩深三次后，那就是他的习惯——你不在时他走的就是这条（note6：三次成功→习惯）。

**环境记得他。** 每件事都在横幅上留下一道不擦掉的痕迹（`Mark`），痕迹反过来改变选项或心智：
| 痕迹 | 谁留下 | 反过来改变 |
|---|---|---|
| 踩出的路 path | 禾 | 他自己会去哪（习惯） |
| 井水位 well | 禾 + 乡邻 | 井干了，「听井边」变成「刨井底」，流言变少 |
| 一小块活苗 green | 禾挑水 | 田伯买地时出价更高；「熬」时多一线希望 |
| 邻家的门板 door | 乡邻 | 走的人越多，「带乡邻」越弱，「走」越近 |
| 田伯门口 gate | 田伯 | 叩得越多，门口多一个看门的，田伯越戒备（田伯也在学禾） |
| 社树下的橡子 oak | 乡邻 + 禾 | 捡光了，瓮里少一条后路 |

**张力 = 两个钟 + 每天关一扇门。** 粟瓮在见底（饥），王的征粮日在逼近（田伯的仓会被搬空）；此外**每天至少关上一扇门**（拍 `closing`）：邻家钉上门板、井见泥、橡子被捡光、田伯的价钱变了。关上的门不再打开，横幅上看得见它关着。你不能什么都要。

**双向建模。** 禾心里有个小田伯；田伯心里也有个小禾（tianbo 对禾的看法随叩门次数、带来的来由、民心变化）。峰值叩门时，两个心智对撞。

验收：bench 跑完一局，`marks` 至少 6 道、来自至少 3 种 `by`；`closing` 至少 4 次；`self` 至少 1 次（空闲玩家时 ≥ 3 次）；每道 mark 的 `effect` 在之后某天的选项/心智里能找到对应变化（sim.test 断言）。

### 4.7 控制约 0.3 的理由（视角与控制一致）
你不是禾，你是他心里的一个声音：能放念头、能改他心里的小田伯、能建议他去哪；**他自己决定做不做、怎么做**。他会拒绝你（执着），并让你看到他没有顺从。

## 五、心智引擎（note6 定稿的可审计有限状态版）
- 单元 → 模块 → 心智；误差 e = obs − pred，eps = π·e；|eps| ≤ 本层阈值就地消化，否则残差 r 上传。每层阈值由性情（耐性）决定。
- 四类操作分开：infer（只改状态）/ learn（只改参数）/ select（只选策略，记 infoGain 与 preference 两项）/ act（唯一改世界）。每次都写 trace。
- 记忆：S = exp(−λ·age)，λ = λ0·(1 − ρC)；摆到眼前一次，C ← C + η(1−C)。
- 设想：用同一结构换上对方参数（禾的信念）跑一遍，得到预测；与真实比较，误差可见；写回一条 tag=imagined 的记忆；小田伯的参数按误差学习。
- 沉淀：同一情境同一做法连续奏效 3 次，编译成习惯，心智不再为它停下来（trace 里看得见「从想到不想」）。
- 规则做日常；只有到达心智层的事（田伯开口、你写给禾的一句话）才交给模型；无模型时全程用规则也能走完，并如实标「规则」。

## 六、机器的身体（只用浏览器读得到的）
- 时钟：深夜来，导师的话更短、东郊的天是夜里的（星与荧惑）；白天来，是白热的旱天。
- 明暗：系统暗色时屋里的灯更暖。
- 前后台：你切走再回来，导师（或禾）在做的那件事往前走了一点，只指给你一件变了的东西。
- 本机存储：记得你的称呼、来过几次、上次停在哪。「让它忘掉我」藏在咖啡厅里：吹灭你座位旁的那盏小灯（页面内确认）。

## 七、演示面板（收起，不在玩家路径上）
按 `` ` ``（反引号）或在左下角长按 1 秒打开：trace（每条是规则还是真的在想）、心智三层的计数、预测与命中、事实账本、「假装离开两小时」（把机器的钟拨快）、「停」（模型调用全部改用规则）、换 seed 重开、忘掉我。

## 八、验收（bench 打印得出来的）
- 首个可操作元素 ≤ 1 秒（门），每幕进场前 3 秒可做的事 ≤ 1 个。
- 每个动作 100ms 内有可见反馈（像素差分）。
- 每屏可见字 ≤ 30（trace 里 line.say 的 chars 与 DOM 采样）。
- 控制台报错 0；帧率 p5 ≥ 50。
- 删字测试：隐藏全部文字，模拟玩家只靠可做的事（data-aff）仍能从推门走到关门。
- 同一 seed 两次运行，事实账本一致；不同 seed 的田伯不同。
