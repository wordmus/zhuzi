# 整个结构：导师 → 导演 → 呈现 → 演员

这份文档把四层与它们的回路画在一处，并指明每一层在代码里住在哪、在画面里怎么看见、现在做到哪一步。三层信件（委托/方案/提示/报告/回顾）的细节见 `docs/design/layers.md`。

```
                    ┌──────────────────────────────────────────────┐
   你（用户）  ───► │  导师（机器的心智）                            │
   停留/跳过/追问   │  • 用户模型与带证据假设（两本册子，可纠正）    │
   纠正假设   ◄───┤  • 感官（时钟/设备/明暗）、灯油、来过的次数      │
                    └───────────────┬──────────────────────────────┘
                        委托(commission) │ ▲ 回顾(retro)
                        「为什么这次给你这个」│  「学到了什么/留下什么线」
                                        ▼ │
                    ┌──────────────────────────────────────────────┐
                    │  导演（造世界、定怎么给你看）                  │
                    │  • 意图→呈现方案（幕/焦点/取舍/预演/停止准则） │
                    │  • 种子规则、方案校验（宪法）、试映              │
                    └───────────────┬──────────────────────────────┘
                        提示(cue)   │ ▲ 报告(report)
                        「这一幕我预期他做什么」│  「他真正做了什么/误差」
                                        ▼ │
                    ┌──────────────────────────────────────────────┐
                    │  呈现（一件作品 = 一个视角 = 约束）             │
                    │  • 十二种「形」：vignette / reveal / walk2d /  │
                    │    chronicle / 四个小游戏 / studio / east3d /  │
                    │    film / gallery                             │
                    │  • 一屏一个焦点；字最贵；可换档（L1 2D / L3 3D）│
                    └───────────────┬──────────────────────────────┘
                        世界交来的拍（Beat）│ ▲ 事实/预测误差/种子
                                        ▼ │
                    ┌──────────────────────────────────────────────┐
                    │  演员（在世界里生活的人）                      │
                    │  • 禾（东郊）/ 田伯（齐地贵族）/ 季（稷下士人） │
                    │  • 单元→模块→心智；不等你；决定写回宏观        │
                    └──────────────────────────────────────────────┘
```

## 信息怎么流（畅通性）

**向下**：委托（为什么这次给你这个）→ 方案（承接与改动）→ 提示（这一幕预期）→ 世界里的拍。

**向上**：事实与预测误差 → 报告（他真正做了什么）→ 回顾（学到什么、留下什么线）→ 写回本机 → **下一次委托因此不同**（可复验：两本册子里纠正一条假设，`commission().why` 当场变）。

**横向**：演员的决定写回宏观（`engine/history`：民心/粮/国力/礼制），跨章账本只增；环境留下痕迹（marks），反过来改下一次的选项——演员与环境共同进化。

**呈现与控制的对应**：给你多少控制由视角决定（旁观 0 / 0.3 / 1）；呈现是约束，不是信息搬运——每一幕都有「不给的东西」。
