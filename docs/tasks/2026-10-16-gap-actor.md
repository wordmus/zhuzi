# 差距③ · 演员的第一人称报告（把"报告"从数据变成"他说"）

依据 `docs/notes/1.md`：交付的是一群心智；**演员的行动是活在世界**。现在演员的报告是数据（`ActorReport`：`{did[], predicted, actual, error, facts[], seeds[], ms}`，见 `engine/layers/report.ts`），长得像机器汇总，不像"他说"。这轮让演员用自己的声音**写 2–3 句**，回导演、也给你看——证据必须真（只归纳已发生的轨迹，没有行动证据就明说不编）。

## 一、要做的事

1. **演员的声音**（`engine/layers/report.ts`）
   - `ActorReport` 加一个可选字段 `voice?: string[]`：**2–3 句第一人称**（每句 ≤18 字，合时代：粟不是米、没有茶；天、社、鬼神、田伯、名分；偶尔带刺，从不解释）。
   - 声音**由证据生成**，不许编：从 `did`（本幕属于自己的行动）、`error`（预演 vs 实际）、`seeds`（种下的概念）、`facts`（交付事实）里取材；没有可归属于自己的行动时，第一句必须是明说的（例：「这一幕我没动手。」）。
   - 每句仍要 `bus.log('line.say', …)` **逐句**发出（一次一句，别整段同屏），保证 bench 的 maxChars 口径不变。
   - 在 `engine/world/lines.ts` 加一份**声音语法**（每位演员一套：禾 / 田伯 / 季 / 桑 / 小石，按现有台词库风格），把"取材→句子"写成可测的纯函数（新文件 `engine/layers/voice.ts` 亦可，但 `ActorReport` 类型只加不改）。
2. **回导演**：报告信件（`kind: 'report'`）里带上 `voice`；工作室（`frameworks/studio/**`）接住报告竹简时，把这 2–3 句**逐句说出来**（现有的 `tell(...)`/`line.say` 通道），导演的对比（`director.compare`）不变。
3. **也给你看**：长卷（`frameworks/chronicle/**`）每一幕的收尾处，留**一句**演员自己的话（同一份 `voice` 的第一句即可），其余两句折叠在同一条目里（默认不展开、点了才出，展开不算主屏限额——按 `verify-entry.mjs` 的口径，如果长卷没有同口径，就只显示第一句并把它写进 `layers.json` 的 payload 供查阅）。

## 二、硬规则

- 只**新增**声音：不许改已有台词、不许改已有 facts/`did` 的语义、不许改信件 kind 与回执时机——旧 run 的可复现性与逐字节回归都靠这个。
- 每屏 ≤1 句 ≤30 字；一次一个焦点；不许文字按钮；不许数字/面板。
- 逐句发声必须仍满足 feedback：上一句出现后 ≤100ms 有可见变化（下一句出现即算）。
- 门槛（`bench/**`、`critic/**`）一个字不许动。

## 三、你的文件边界（**严格**）

拥有：`engine/layers/report.ts`、`engine/layers/voice.ts`（新）、`engine/layers/types.ts`（只加 `voice?: string[]`，**别动别处**）、`engine/world/lines.ts`、`frameworks/studio/**`、`frameworks/chronicle/**`、`docs/design/actor-voice.md`（新）、`runs/studio/<你新产的 seed>/**`（新 run）、`runs/fifty-years/<你新产的 seed>/**`（如需）。

**绝对不要碰**（另一个工正在写）：`frameworks/desk/**`、`engine/mind/**`、`engine/layers/mentor.ts`、`director/**`、`app/main.ts`、`bench/**`、`critic/**`、`frameworks/vignette|console|film|gallery|east3d/**`、其它既有 runs 产物、git。
