# S3 · 小游戏：《稷下谁在说话》《五德转盘》（季的视角）

你是 `docs/tasks/2026-10-15-wave1-00-overview.md` 里的 s3。**先完整读 `docs/design/minigame-contract.md`（冻结契约）**，再读 `frameworks/reveal/index.ts`（样板）、`components/paint/**`（画具）、`eras/zhanguo/style-bible.md`（材质）。

两个小游戏都从**季**（稷下士人）的视角出发：稷下学宫最盛的临淄，诸子百家在一间堂上说话；季想站住、想上书。两个游戏都是导演编排里的独立一幕，完成后把事实交回。

## 一、《稷下谁在说话》`frameworks/jixia-speakers/`

**玩法**：堂上几位学士各说一句话（漆画剪影，侧面，冠服不同）；你替季判断**这句话是谁说的**（儒 / 道 / 法 / 墨 / 名 / 阴阳，六块牌）。判断对了，堂上的目光聚到季身上一点（学士点头、上前一步）；错了，一片低声议论，那句话落成一颗种子（之后可能被重新掂量）。

- 3–5 回合；台词必须是真实可靠的先秦语录或学术上公认可归属的句子（《论语》《老子》《韩非子》《墨子》《公孙龙子》《孟子》《荀子》等），**每句在 README 里写归派理由与出处**；有争议或民间误传的句子不用。
- 每回合：一句话出现（`ctx.lines.say`，≤ 18 字）→ 六块学派牌（`ctx.aff`，名字短：儒 / 道 / 法 / 墨 / 名 / 阴阳）→ 点牌 → 立刻反馈（牌发光、学士反应、说一句 ≤ 12 字）。
- 结束：正确率 ≥ 门槛时，季「在稷下站住了」；否则「被问得答不上来」。产出事实与 `metrics`（正确数、最高连对）。
- 字要少：牌的标签是仅有文字；其余靠人物与动作读出来。

## 二、《五德转盘》`frameworks/wude-wheel/`

**玩法**：邹衍的五德终始（五德相胜）。一面青铜转盘，五格：木 / 火 / 土 / 金 / 水。游戏给一段「前代之德」（周为火德），你把指针转到**胜它的那一德**（水胜火 → 齐当为水德），转对了轮盘亮起相胜的链（木胜土、土胜水、水胜火、火胜金、金胜木）；转错了，堂上有人摇头，给你一点线索。
- 2–3 轮（夏木 → 商金 → 周火 → 齐水），由易到难；每轮一句话提示（来自「邹子」），不报数字。
- 交互：转盘可拖（`ctx.aff` + `onDrag`）或点五格；转到正确格时停下并亮链。**必须只用可点击/可拖的 affordance 就能玩完（删字测试）**。
- 结束：全对 → 季的简上多一段「天命」；有错 → 天命之说被学士驳了一句。产出事实与 `metrics`。
- 历史口径要在 README 里写清：五行相胜次序、周火德、秦后来自居水德；齐的这一段属于稷下学宫的思想环境（阴阳家），**不要写成既成史实**。
