# ENTRY-ART · 分层入口的场景化返工（结构不动，画要重画）

前置：ENTRY 已完成**结构**（案上→导师→导演→呈现的逐层展开、每层可退回、右侧窄抽屉只装导师明细、去掉灯油、bench 9/9）。**问题**：它把每一层画成了扁平原型——石板青底色、悬浮纸片、纯文字按钮（「往里看」「看它在做什么」「退回」），既不是漆画场景，也不是用户要的「场景化」。用户原话：「现在的界面混在一起……需要分层，保持简洁，采用层层展开的方式……不要把某一层放在侧边 UI 之外堆在一起」＋更早的「做一版场景化的」。

目标：**结构与行为一律不动**，只把四层与抽屉**重画成漆画场景**——用 `components/paint` 的语言与色板，焦点靠光与视线，动作做成场景里的物件，文字降到最低。

## 一、每层要画成什么

| 层 | 现在（扁平原型） | 要改成（漆画场景） |
| --- | --- | --- |
| **L0 案上** | 石板底上一张桌子＋红方块＋两行字 | 黑漆夜里的矮案（`lacquerGround`＋`props-room` 的 `lowTable`）：案上**一张写着「旱」的票根**（程序化篆意字，与既有票根同一画法）＋一盏小灯（`light.flame`）；案面有漆面反光与细金边。**唯一动作＝把票根拿起/往里推**（物件本体可点，悬停时票根抬起、灯焰亮一点）；导师一句 ≤18 字（`ctx.lines`，ink light）。**不要纯文字按钮。** |
| **L1 导师层** | 纸片＋「还不知道你在意谁」＋文字按钮 | 导师本人（`paint/figure.ts` 的 `makeFigure('mentor')` 或同款深衣侧影）在案后抬头，**视线**指向案上的一枚**竹简/帛条**；它对你想什么＝**它说出的 2–3 句短话**（≤18 字，逐句出现，`ctx.lines`，不排成 UI 列表）；它对你「在意什么」不确定时，竹简上是**空白**（只留墨痕），一句话由它口述。动作：看它（等它说完）／退回（画面左缘一枚小铜符，可点）。 |
| **L2 导演层** | 纸片＋两行字 | 漆屏风前**两张矮案**，各放一件**毛坯**的画（动画＝一条胶片格、图集＝一叠帛、3D＝线格小方、游戏＝小棋盘——小示意即可）；两案之间挂一盏灯；谁在做哪件用**案上的东西**表示（不写「在做/已交付」四个字）；导师的视线从 L1 移到案上表示「看它在做什么」。动作：看架上（画面右缘的门/架）／退回。 |
| **L3 呈现层** | 纸片＋作品行 | 现有作品的**木架侧视**：每件一枚帛条/简，标题用小篆意字（程序化），盖印的有一枚朱印、未盖的用麻绳系着；一次只聚焦一件（其余退暗）；「拿起/进入」＝把帛条抽出，画面右缘的门亮起；进入仍是新标签页。 |
| **侧边抽屉** | 通用 DOM 抽屉 | 仍是 DOM（科层明确、可键盘），但**配色与字体对齐漆画**：黑漆底、金线分隔、「它眼中的你」用帛条样式列出（假设＋证据＋置信度），可纠正；**不要**石板青、不要圆角白卡片。 |

## 二、硬规则

- 色板只用 `components/paint/palette` 的 PAL/TONE（漆黑/金/朱/赭/帛/青铜/夜蓝/粟）；**禁止**石板青、纯灰、现代卡片 UI。
- 焦点靠光（灯焰、光斑）与**视线**；动作是**物件**（票根、铜符、帛条、门），不是文字按钮；每屏 ≤1 句 ≤30 字（抽屉不算主屏）。
- 结构与行为**不许变**：仍四层、仍可退回、仍只装导师明细的抽屉、仍无灯油、仍 bench 9/9（`verify-entry.mjs` 必须继续全过）。
- 字：台词用 `ctx.lines`（Noto Serif SC 栈）；标题/字用程序化篆意字形，不依赖字体。

## 三、你拥有的文件与边界

- `frameworks/desk/**`（重画四层与抽屉样式）、`assets/library/desk/**`（新画具：票根、铜符、竹简、帛条、木架、朱印；每件 recipe）、`docs/design/desk-map.md`（补「场景化返工」一节与新旧对比）。
- 只加不改：`app/main.ts`、`director.ts`、`validate.ts` 的既有一切条目；`runs/index.json` 只读。
- **不要碰**：`frameworks/vignette/**`、`frameworks/console/**`、其它 frameworks、bench 判定与门槛、critic、既有 runs 产物、git。
