# CAFEMAP-ART · 场景化返工：让四站成为物件，而不是框图

用户反馈（原话）：**「做一版场景化的，而不是单纯的 UI。我要实现场景化，即在 UI 中显示整个产品的导师层、导演层等信息。」** 现状问题（截图已确认）：咖啡厅底子是好的，但四站是「框」画出来的——灯油台/工作台/作品架都用 `strokeRect` 金线描外框，假设卡是一块平白纸，架子空着时是一块空矩形加一句字，整体像「咖啡厅上贴了一张示意图」。

目标：**在同一个漆画场景里**，把导师层（它眼中的你、灯油分配）、导演层（谁在做什么、年谱）、呈现层（作品与盖印）、门 都做成**场景里的物件**，用光与视线表示焦点，**去掉示意图式的框线**；信息可读（看近才读，≤1 句/屏），但首先是能看懂的画。

## 一、逐站的画法要求

1. **① 灯油台**：一张真实的矮案（沿用 `components/paint/props-room` 的 `lowTable` 画法），案上排几只青铜小灯，**灯焰高低＝分给各世界/作品的份额**（数据同现状）；陶壶倾倒动画保留（`pourProgress`）。**不要外框**；要「可倒油」就靠灯焰的呼吸与你上次挪动的那盏灯（`visit-changes` 的 `currentLampX`）已经在了。
2. **① 导师的假设（它眼中的你）**：矮案一角立着一只小木架，插着 3–5 枚**帛条/竹简**（每条一假设）；条的长短或墨色深浅暗示置信度；被纠正过的那条留着刮改的痕（旧痕不抹）。看近（悬停/点击）用一句 ≤30 字读出该条。
3. **② 导演廊**：两张真实的矮案（基础导演 / 叔衡）。案上放他**正在做的那件**的「毛坯」——按作品形式画**小示意**而不是文字：动画＝一条胶片格、图集＝一叠帛、3D＝一枚线格小方、游戏＝一块小棋盘；旁边有印与笔。**年谱**：墙上钉一张旧纸——第一天的草图（线稿）＋一道朱笔「改」线；纸要有纸的样子（纸纹、卷边、钉眼、轻微歪斜），不是平白矩形。
4. **③ 作品架**：一只真实的木架（侧视），架上每件作品＝一枚**帛条/简**（盖印的旁边一枚朱印；未盖印的用麻绳系着）。**没有索引数据时**：架上是两三枚空白简与薄尘，视线看过去才由导师说一句「架子还空着。」——不要空矩形＋居中文字。
5. **④ 门**：保持原样（地标不动）。

## 二、焦点与读字

- 焦点靠**光**（灯焰变亮、光斑、导师的眼神转向）与**位置**（走近一站），不用描边矩形、不用标签。
- 每屏 ≤1 句、≤30 字；看近才读（悬停 0.8 秒或点击）；前 3 秒 ≤1 个可做之事；100ms 内反馈。
- 信息密度靠物件（灯焰高低、条的长短、架上有无朱印），不靠文字。
