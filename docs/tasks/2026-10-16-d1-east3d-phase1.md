# D1 · 东郊 3D 呈现（方法 A · 阶段一，three.js）

前置：D0 的 `docs/3d-design/east-suburb/prd.md` 与 `assets-plan.json`（设计阶段，可能因额度中断但文档已落盘则照用）。本地链路已验证：`Blender 5.1.2 headless → GLB → 读回` 可用（示例脚本 `/tmp/east3d-spike/spike.py`，样例产物 `/tmp/east3d-spike/spike.glb`）。

目标：把《旱》里的「东郊」做成一件**独立的 3D 呈现**（three.js，浏览器内，**不用 Unity**），走导演管线产出新作品。**硬约束：不改动当前已经做的任何呈现**——现有 frameworks/intents/runs 的玩法与产物不许变；只做加法（新框架、新资产、新 intent、注册表加一行、director 只加一个 act set）。

## 一、内容（以 D0 的 prd 为准；没有 prd 时按此）

- 场景：白热的旱天（帛色天光）、一枚朱红太阳、龟裂的黄土田、枯黄的粟丛、跪在田缝边手按裂缝的禾、远处桔槔井与老桑树；层叠的远坡。
- 两个动作：**碰田缝**（近景推进、手触、土屑落下）、**望天**（镜头上摇、日轮、禾直起身）；望天后禾说一句 ≤18 字（沿用「天老爷，你是忘了东郊，还是忘了我？」或更短）。
- 规格：40–60 秒；一屏一个焦点；进场前 3 秒 ≤1 个可做之事；每屏 ≤1 句 ≤30 字；动作 100ms 内有可见反馈；p5 帧率 ≥50。
- 账本语义与 L1 的东郊一致：没有新的世界规则；它是一件呈现，不改变事实。

## 二、要交付的文件

> 阶段零已完成（本机程序化验证）：`assets/library/east3d/build.py` 能生成 six 件 GLB 并导出 recipe；`assets/library/east3d/view.py` 能渲染三机位校样（产物在 `docs/3d-design/east-suburb/views/`）。**已验证的返工点**（照此做，不要重蹈）：
> 1. **地面**：几何裂缝在 Workbench 下读成「垄」不是「裂」；漆画风格应改走**平面 + 程序化裂缝纹理**（three.js 里用 canvas 生成抖动 Voronoi 线网的贴图 + 低起伏几何），而不是靠网格位移。
> 2. **枯粟**：细圆柱杆 + 球穗在远景读成小球；改成**描边式的片状丛**（若干细长平面/锥体成簇，略带弯曲，面朝相机不过度明显）或把杆加粗到 0.04m、穗拉长到 0.4m。
> 3. **禾的替身**：锥台躯干 + 球头只读成一只锥；至少要把头/肩/臂的轮廓做出来（或用 Tripo 资产直接到位）。无 Tripo 前先把姿态做对：跪坐、前倾、一臂下探触地。
> 4. 构图：参考图是「近景特写」——禾与田缝占画面下半部三分之一以上，井/树只在远处做剪影；三机位渲染里当前禾几乎不可见，D1 要把相机收紧并验证。

1. `assets/library/east3d/**`：本地程序化生成的 GLB + 每件 `recipe.json`（脚本、seed、面数、原始「来源：本机程序化生成，无外部素材」）。建议件：`ground.glb`（龟裂地面）、`millet.glb`（枯粟丛，实例化）、`well.glb`（桔槔井）、`tree.glb`（老桑树）、`pots.glb`（陶罐）、`he-placeholder.glb`（禾的漆画风替身；Tripo 到位后放 `tripo/he.glb` 替换）。**总面数 ≤ 150k、单贴图 ≤ 2048、材质 ≤ 8。**
2. `frameworks/east3d/**`：导出 `east3d: Framework`（框架 id `east3d`）。自建 WebGL canvas（挂进 `ctx.stage.root`，退出时清理），three.js 场景、相机、光照、材质；两个 `ctx.aff.add()` 动作与一句台词；`data-aff` 名字：`east-crack`、`east-sky`。确定性：用 `ctx.rng.fork('east3d')`；同 seed 同结果。无网络请求：three.js 从 npm 依赖引入，GLB 从 `assets/library` 打包进单文件产物。
3. `intents/east-suburb-3d.json`：id `east-suburb-3d`，form `vignette`，perspective「你」，era `zhanguo`，director `shuheng`，时长 1 分钟，notes 写明这是 L3 的独立呈现、不改变既有作品。
4. `director/pipeline/director.ts`：给这个 intent 加一个 act set（加法，别动既有分支）。act id `east3d`，framework `east3d`，focus `east-crack`。
5. `app/main.ts`：注册表加 `east3d` 一行。
6. `dev/east3d.html` + `dev/east3d.ts`：自测页（假 ctx，合成 PlanAct），页面完成时 `window.__zhuzi.done = true`；含 `window.__trace`。
7. `frameworks/east3d/README.md`：元素/动作表、验收命令、Tripo 替换槽位说明。

## 三、验收（都要打印）

```sh
pnpm typecheck
ZHUZI_ENTRY=dev/east3d.html ZHUZI_OUT=dist-east3d npx vite build && pnpm bench dist-east3d/dev/east3d.html
pnpm present --intent intents/east-suburb-3d.json --tier L3 --seed 2
pnpm bench runs/east-suburb-3d/2/L3
pnpm bench runs/fifty-years/3/L1          # 既有作品不回归
```

- 两处 bench 都必须 **PASS hard 9/9**（含 layers；errors 0、first3s 1、max-chars ≤30、notext PASS、repro PASS、fps-p5 ≥50）。
- 产物体积：单文件 index.html ≤ 12MB（three.js + GLB 之和）。
- 截图 `runs/east-suburb-3d/2/L3/shots/` 能看出：龟裂地面、禾、日轮、两个动作各一张。

## 四、不要做

- 不改现有 frameworks（vignette/reveal/walk2d/chronicle/四个游戏/studio）的行为，不改现有 intents，不手改 runs 产物，不跑 git 操作。
- 不引外部 CDN、不联网加载资源；不引 Unity。
- Tripo 资产属于阶段二（等 `TRIPO_API_KEY`）：本阶段只留槽位与 recipe 占位，不许伪造 Tripo 产物。
