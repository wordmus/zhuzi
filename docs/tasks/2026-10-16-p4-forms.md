# P4 · 两种新形式：图集（gallery）与短片（animatic/film）

依据：`docs/presentation-pipeline-brief (2).md` §5/§6（电影管线：节拍→镜头表→关键帧→animatic；animatic 本身是成立的电影形式，不是预览；镜头预留热点，可从一帧派小游戏）与 §4 档位（L2 = + 图像生成）；`docs/策划文档v0.2 存档.md` §10（电影是零交互的呈现，图集是只有一个简单环境的游戏）、§19（《三人看天》是主线）。

目标：新增两个**框架**与两件作品，走导演管线产出，**不改动任何既有作品**：
1. `film`（短片/animatic）：镜头表驱动，L2，作品《三人看天》——同一片天，禾（农夫）、季（稷下士人）、田伯（贵族）三种视角，60–90 秒。
2. `gallery`（图集）：可拖拽展卷、记忆位置，作品《作品架》——把已交付的作品与改版史铺成一条长卷（plates 可用现有 runs 截图 + 概念图，带来源与许可）。

## 一、共享契约（只增不改）

`engine/types.ts` 增：
```ts
/** 短片的一镜。image 指 assets/library/ 下的资产 id；text 每镜 ≤1 句、≤30 字。 */
export interface Shot {
  id: string;
  image: string;
  ms: number;                                     // 时长
  move?: 'still' | 'pan-left' | 'pan-right' | 'zoom-in' | 'zoom-out' | 'tilt-up';
  who?: string;                                   // 说话人（字幕用）
  text?: string;                                  // 字幕：≤1 句
  sound?: string;                                 // 音效名
  hotspots?: { id: string; x: number; y: number; r: number; represents: string }[];  // 画面里可点之物
}
```
`PlanAct` 增 `shots?: Shot[]`（加法）。`PlanElement` 增 `asset?: string`（图集 plates 用，加法）。

## 二、`frameworks/film`

- 读 `act.shots`；逐镜播放：关键帧图（`assets/library/<id>`，Vite `?url` 打包）+ 运镜（pan/zoom/tilt 的 2D 变换）+ 字幕（每镜 ≤1 句，位置随镜而定）+ 音效（`ctx.audio`）。
- **热点**：每镜可有 1–2 个 `hotspots`，注册成 `ctx.aff.add()`；点中后短暂停住并说一句该物的台词（≤18 字），随后继续。
- **结束**：总时长即镜头表之和（60–90 秒），播完 resolve；`window.__zhuzi.done` 由 main 置位。
- 规格：一屏一个焦点；每屏 ≤1 句；100ms 内反馈；无模型依赖；`ctx.rng` 不参与（同表同播）。
- 验收：`pnpm bench runs/three-look-at-sky/<seed>/L2` 必须 PASS 9/9（**注意**：注意探针的 `notext`——字幕隐藏后仍能播完；`first3s` 只允许 1 个可做之事——热点一次只注册一个）。

## 三、`frameworks/gallery`

- 读 `act.elements`（每件=一 plate，`asset` 指图片）；横向拖拽/滚轮展卷（像《诗经长卷》），**记忆位置**（`ctx.store`，再次进入从上次处继续）；每 plate 一句 ≤18 字小字（或用 `act.lines`）；点一件 → 追问一句（≤30 字）；走到最右或「收起」即 resolve。
- 规格同上；`ctx.aff` 注册拖拽与「收起」；窄屏纵向/一列。
- 验收：`pnpm bench runs/shelf-gallery/<seed>/L2` PASS 9/9；拖拽与位置记忆有自证（无头或脚本断言）。
