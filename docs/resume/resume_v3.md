## 独立研究 · 产品原型 | INDEPENDENT RESEARCH

### Fount — 持久 Agent 运行时与人工心智 | 独立研究 / 架构设计

面向长期存在的 Agent 系统，把人工心智定义为持续感知、注意力分配、历史积累、经验压缩与行动倾向形成的运行循环。

- **分层运行时** 机器 agent 负责资源、经验分发与机器自我认知；内层 agent 负责世界演绎与角色主体，让世界产物反过来成为下一轮的输入。
- **认知循环** 感知 → 记忆 → 预测 → 行动 → 误差 → 沉淀，角色按所处环境、关系与身份形成各自的理解。
- **注意力与记忆** 设计注意力 + 分布式注意、活跃 / 长期 / 冷记忆分层、Agent 生命周期、tick 感知、异常上报、资源分配与经验压缩。
- **稳定边界与进化** 以 API 为稳定边界，把成功决策沉淀为 skill、规则、工具或 Agent 模板，让系统以低成本绕过一次性探索。
