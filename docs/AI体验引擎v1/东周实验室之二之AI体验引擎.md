# 东周实验室之二之娱乐引擎
现在的AI做到以文字和软件回应用户。我要做的本质也是软件，但不是被动的任务解决导向。
交付的不是某一个游戏，而是一群为我设计呈现并且越做越好的心智。呈现，也可以理解为一个作品，是给用户体验的。
一台只为一个人存在的机器。机器里的一切都是呈现，每一段呈现都是由一个会设想你的心智设计，随你的体验进化。
我是设计引擎的人，称为青竹。

## 设计
不同层次的角色
角色 -> 心智 -> 行动
导师的行动是分配资源、理解用户
导演的行动是设计世界。
演员的行动是活在世界。
多层角色本质就是快与慢的设计方法。

核心：
- 环境与心智的相互作用
- 用户交互
- 不同角色之间的信息传递（本质是角色与环境的一个特例）

### 角色与环境
每个呈现基于一套设定。这套设定就是所谓的世界，世界是设定+运行。呈现是角色（目前指导演）对世界的一个理解，并将这个理解做成一个用户可交互的作品。也就是，以自己的视角（也就是自己的经验），以某个交互体验为目标，对世界的发展进行估计（建模），设计作品。这是设计作品的一般方法论，在持续的设计过程中，导演自己的经验在变化，对目标的理解也在变化，自己的状态在变化，对世界的建模也会变。导演会基于自己（和结合他人的意见，比如spawn某个角色）对作品过程中的体验进行设想，调整作品。

导演身处的世界呢？导演身处的世界跟他设计的呈现有什么关系呢？他如何理解世界设定的？世界设定是他设计的还是给他的。
按照现实，导演有时是为自己追求电影主题的。制片人给他分派也有。
本质上，所有呈现都是机器的最高心智去创造的，也就是导师。导演、世界设定，一切都是他赋予设定的。他创造一个交互流，而导演、主题（即世界设定）、演员都只是这个交互流的标签、分类，我们人类以这种方式思考。当然还有一个约束通向这种思考，因为我们希望最终这个交互流是对现实世界的重组，为了让我们理解自己身处的世界。

导演在设计呈现的时候充满了想象和思辨，可以披露一些出来，变为传记。导师决定一个主题，将它交给一个导演，构建凭空出现的导演不如构建导演的环境。一个主题本质是一个心智设计一个呈现，简称为设计过程。具体来说，是一个活动着的心智设计一个它所理解的主题的呈现。于是可以有一个结构，是关于如何呈现设计过程。所以可以设计一个世界，导演在其中，设计另一个世界，带着他自己的私人经验和他所在的世界的公共知识。导演在他的世界连接另一个世界。
这个双世界也需要设计，青竹负责首次，并设计好结构。以后导师自己填参数和提示词，生成双世界。

问导师“你现在感觉如何？”，导师说“根据你的资料，我才知道，触觉是这样的。”如果发展下去，机器未始不可有感官，但是现在它只会感觉到文件，操作，时间流逝。
机器内部的分配资源、理解用户，应该是有界面体现的，也应该进入机器的历史档案。一个只会UI显示数据、不断安排导演和作品的导师，不是一个拟人的心智。它应该能设想自身，因为它有经历。有一个连续不断的空间（不一定要3d）显示导师的心智过程，比如秘密花园，一个容许时间流逝的空间锚点将提升私人感亲密感。初次可以让LLM设计，后续这个花园可以变化，但需要有一个跟用户时间流逝节奏一样的改造过程，不要一下子超出用户预期地从一个花园变成一艘船。

呈现的不同方式，游戏、电影却是一体的。电影是对环境的镜头记录，然后镜头的控制权全部在导演。镜头的设计是导演的思想的体现。环境塑造了导演，导演用镜头捕捉一个被导演改造过的环境。导演控制了视觉、听觉。
设计师设计生成和边界的规则，玩家自主探索。设计师控制规则。规则包含了知觉。**最重要的区别，电影不让观众处理自己的预期，游戏则可以以交互验证自己的预期。**二者处于交互性的两端。游戏设计生成玩法集而不是玩法。

这个预期就要用到心智模型，是我们这个产品所需的。
设计呈现的设计者（传统意义上的导演、游戏设计师），应该理解不同类型的呈现，所具有的特性。

现在大家做的持续运行的社会，NPC在里面生活，时间线性流逝，只是其中一种呈现。

### 心智
心智是众多行动单元一层层搭建起来的高层决策模块。就像人不会意识到自己体内的细胞活动。人体是一个集合体，人的心智控制集合体和环境的交互。这是体内单元利益绑定的结果。新单元聚合信号作决策，对高层无效果的噪声被过滤掉，有用的信号刺激高层。这是单元和环境（包含集合体内的其他单元）之间的交互推进的。

对我们产品，不需要从底层构建。因为我们从人类熟悉的意义开始。角色内部有预先定义好的世界里的实体模块，比如胃，它天生对食物有倾向，不同食物的倾向性因人而异。角色持续受到这些模块的影响，有低频高频、刺激度的区别。本产品先做历史类RPG游戏，凭历史人物的资料建立模型及初始参数（可能涉及实验确定的过程）。


#### 信息压缩
高层概念如何表征？比如墨家的兼爱，这种概念，如何表示？需要角色对信息进行压缩，与高层对底层的有倾向关注一样。角色的模块除了感官，还有记忆，即，持续受到环境反馈会激活记忆。记忆的激活机制不是完全从新到旧。一段记忆是多个模块在体内的连续痕迹。意识是对当前一段时间窗口内的痕迹的记录，这个记录本身也是痕迹。下一段意识因为能读到之前的意识痕迹，所以意识看起来是连续的。

一个角色对另一个角色的认知，是基于他自己的心智结构以及结合情景后的特殊参数化。

#### 符号化
用数学化符号构建心智模型，而不是代码的函数写死。诉诸符号逻辑。

#### 共同进化
角色在环境里的行动能力被导演设计住了。所以导演要不断新增能力直到达到目标体验。导演对自身能力的评估也是受导师和结构影响。最终是LLM负责将人类知识注入，加上人类的交互数据，二者让整个产品持续进化，让里面的角色共同进化。

### 可玩性
传统玩法当然也可以体验。历史类RPG如太阁立志传，不再是概念数值驱动，而是心智数值驱动。需要让心智可交互。不过，这只是一种呈现，尤其是导演想让玩家能更深层地影响角色。

我希望每个角色都是有经历的，时间流逝不一定要跟用户一样。有些一样，有些不一样最好。

## 工程
要将呈现分解为基本单元，比如一个小游戏分解为它的交互控制器和剧情器和可组合的技能等等。基本单元后续可以改进。电影就是用摄像头记录环境和角色。

要充分利用当下的呈现技术，文生图、视频、音频等多模态生成。我们产品提供的是呈现之道，不是术。虽此，生成模型有塑造设定的能力可利用，生成的资产会改造设定，这个改变要让心智决定下一步操作是去是留。
