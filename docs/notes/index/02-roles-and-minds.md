# 02 · 角色与心智

**一句话**：导师、导演、演员是三种完整角色，共用一套「单元搭起来」的心智结构，环境和经历只调参数、定性情。

## 现行版本

- 三种角色定义（最干净）：`note7.md`（= `东周#v4` 尾段）
- 心智结构定稿：`note6.md#关键不是环路`（分九小节校对版）
- 心智模型 / 视角：`东周#v7 心智模型` + `note9.md`（更全）

## 要点

- 三层角色与各自环境：导师（最外层环境 = 机器文件与算力）；导演（环境 = 它构建的呈现世界 + 导演们共同生活的世界）；演员（与世界交互）（`note7.md`；`东周#v4`）。
- 导演与演员的关键差别：**世界能否多视角**（`note7.md`）。
- 所有角色都是完整人格，共享底层心智结构，只按设定调参 → 经历不同而性情不同（`note3.md` 第 4 条；`note.md` 第 21 条）。
- 导师职责：用户交互数据分析与喜好建模（"制片人"而非纯数据）、资源分配、管理导演、制定世界构建计划（`note3.md` 第 2 条；`note.md` 第 20 条）。
- 导演职责：交付呈现（不是世界）；发布前反复调整、与演员讨论；发布后成事实；导演也通过"呈现"验收自己的作品（类似 LLM agent 用 computer use 验收）（`note.md` 第 9、16–19、38 条）。
- 心智结构：人是单元搭起来的；单元共性 = **预测误差-行动反馈-参数调节**；三大反应 = 反馈 / 前馈 / 模型预测；心智 = 最高层感知；行动 = 感知单元的空间移动（`note6.md#关键不是环路`）。
- 视角 / 心智模型 = 用自己的心智结构构建别人的结构（theory of mind）；算力越高，构建越充分（`note8.md` 第 2 条；`note9.md` 第 1–2 条）。
- LLM 的作用：以超出当前可行动集合的方式行动（用上层材料改造本层结构）；充当翻译（机器某层 ↔ 人类语言）（`note9.md` 第 3 条）。
- 角色与环境共同进化：一个角色的环境可能是另一个角色的产物（`note3.md` 第 5 条；`东周#v5 俯瞰` 重点 2）。
- 培育对象：培育的是机器 agent 本身，不是某个世界里的某个角色（`东周#东周实验室`）。
- 记忆机制：衰减一直存在，摆到眼前一次就记牢一档（间隔效应）；巩固过的更耐久；检索诱发遗忘是抑制而非删除（`note6.md#记忆：不用一条曲线` 一节）。
- 情绪与内感受：按预测需求预配资源（allostasis），情绪是推断出的标签而非传感器真值（`note6.md#单元、模块、资源`）。

## 坑与边界

- 「单元基于共同目标自动长出高一层模块」是**产品架构选择**，不是被理论证明的神经事实（`note6.md#单元、模块、资源` 的诚实边界）。
- 「行动 = 移动感知」的准确说法是「行动通过移动身体去改变感知」（`note6.md#最贴近这个设想的理论组合` 对 PCT 的校正）。
