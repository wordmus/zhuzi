# 04 · 东周实验室与玩法

**一句话**：第一个世界做战国临淄；实验室研究「有限机器里的存在如何获得连续性」，玩法是玩家影响历史人物心智的 RPG / 观察实验。

## 要点

- 首个世界：战国 · 临淄（`../策划文档v0.2 存档.md` 第六节）；先做东周、明朝、古罗马三个轮廓，重点东周（`note4.md`）。
- 研究命题：「有限机器里的存在，怎样获得连续性」；玩家面对的问题是「当机器真的开始创造拥有过去的人，我们是否还可以把算力只当作资源」（`东周#东周实验室`）。
- 分辨率机制：世界大部分以低分辨率演化，聚焦处像一束光打出高分辨率，城市与人群从统计结构里"显影"；资源重新投入 ≠ 加载地图（`东周#东周实验室`）。
- 硬边界：**被低分辨率模拟过的过去，不能事后假装自己曾被高分辨率模拟过**（同上）。
- 实验对照：心智"有中间层 vs 无中间层"两个版本；人物能做的操作是**更新结构**，而不仅是输出动作（同上）。
- 玩家视角：玩家影响一个角色的思想，角色平时自主行动（LLM）；所有历史人物用当时的思维框架去感知和决策；初版类似《太阁立志传》的 RPG，可当君主 / 侠客 / 士人（`东周#个人视角`）。
- 同一时代的人共享一个底层思维框架，按出生地、职业、经历长出独特思维（`东周#个人视角`）。
- LLM 使用分层：日常决策规则驱动，紧要事件与玩家交流才用 LLM，且按场景智能需求选用不同强度的模型（`东周#个人视角`）。
- 版本路线（LLM 逐版增强）：v1 演员 → v2 剪辑师（定 UI 与呈现信息）→ v3 导演（世界演化 + 资源调度）→ v4 导师（统御整机）（`东周#个人视角`）。
- 六种终局结构（AI 游戏目标设计）：① 固定终局、开放过程；② 多终局、由过程内生；③ 玩家自定义目标、系统编译为可验证条件；④ Agent 给玩家生成目标（有出现—强化—失效—生命周期）；⑤ 没有传统胜利、只有不可逆承诺；⑥ 终局是理解某个智能体（`东周#东周实验室`）。推荐演化路径：gameplay → emergent goal → commitment → new gameplay。
- 记忆规则：数字人的记忆不能随意抹去 / 删除，否则会错乱、死亡；被抹去记忆的死亡也应让玩家恻隐（`东周#东周实验室`）。
- 内容框架：内置游戏框架 + 支持无限增加；作品有"介绍入口"，元素可解锁（`东周#v5 俯瞰` 第 7–8 条）。
- 表现手段：思想尽量物质化（心智地图可视化）；用装置、建筑、场景表达认知与情感，例如春夏秋冬用转盘（`东周#个人视角`）。
- 护城河设想：时代 × 心智结合，并以物质的形态交互；时代包方便插拔更换（`东周#个人视角`）。
- 研究定位表：笔记里有一张「你的命题 vs 最接近的前沿 vs 已做到哪一步 vs 剩余空位」的九行对照表（本地长期心智、个体心智—文明智能发育关系、感官增加后的架构重组等）（`东周#东周实验室`）。

## 坑与边界

- 玩法根基未定：第一版历史游戏怎么玩、玩家为什么有权调配资源，是作者自己标出的困惑（`零散.md` 末段）。
- "没有中间层"的实验版本与 note6 的九单元心智是两套设定，读的时候别混用（`东周#东周实验室` vs `note6.md#关键不是环路`）。
- `note6.md` 的代码落点 `demo/src/units.js` 不在仓库里。
