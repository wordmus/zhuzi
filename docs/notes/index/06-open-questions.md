# 06 · 未决问题与张力

## 玩法与产品

- 第一版历史游戏到底怎么玩？玩家为什么有权力随意调配资源？（`零散.md` 末段）
- 产品给玩家的第一面是什么？前 N 个呈现如何与现有游戏、电影做出区分？（`零散.md`）
- "这种剪辑方式能产生其他游戏和电影无法产生的情感体验？"（`东周#东周实验室`）
- 怎样让导演"懂得组织呈现方式打造作品，并且越来越好"？（`note.md` 第 20 条）
- 基调：只有科研意义的游戏不行，AI 科学家需要更强的动力——暂定"研究人类"，东周只是起点（`东周#东周实验室`）。
- 是否需要独立流逝的世界？（`note.md` 第 46 条；`东周#v8` 的"折叠"只算部分回答）
- 呈现交付后是否可以变化、如何兼容旧呈现？（`note.md` 第 47 条）
- 界面不要数值 vs 导演需要量化标准与停止准则：张力在 `东周#v1` 第 8 条 与 `东周#v3` 第 4 条 之间 → 倾向"标准内部化，不显示为数字"。
