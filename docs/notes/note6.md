# note6 · 人是由单元搭起来的

（下面是这一条的原话，按意思分了段，字句尽量保持原样。）

## 一、关键不是环路，是单元

关键的不是体内的环路，而是人是由众多的基本单元搭建起来的，其中最重要的是感知，包括空间、温度等等。

## 二、感知多了就要决策，于是有心智和记忆

感知的东西多了，就需要决策，所以有心智，有记忆机制，比如有艾宾浩斯遗忘曲线。

## 三、它们一直在跑

人在环境里，所有感知模块在运作，记忆模块也在持续运作。

## 四、行动是什么

人的行动本质是感知单元的空间移动。

## 五、体内还有专门分资源的

人体内也有单元负责分配资源。

## 六、心智是最高层的感知

心智是最高层的感知，底层信息它不知道，比如哪个细胞毁灭了，它不知道。它只知道整体性的信息，是人体在环境里的整体信息。

## 七、单元的共性，和它的三大反应

因为任何单元的共性在于 **预测误差 - 行动反馈 - 参数调节**。反馈反应、前馈控制、模型预测是基本单元的三大反应。

## 八、高层模块是这样长出来的

单元之间交流，会基于共同目标来产生高一层的模块，高层模块更关注高层的信息，负责调节整体。所以心智也是这样产生，负责最高层的信息。

## 九、怎么做一个持续存活的角色

如何做一个持续存活的角色，就是信息输入角色后，启动预测误差传递，向关联的单元传递。最终可能传递到心智，也可能不，仅仅由底层的模块或者单元解决。

# 二、相关理论（调研）

（两个调研稿整理后的结论。**分清三件事**：数学框架、神经机制假说、工程近似 —— 它们不是一回事。）

## 1. 最贴近这个设想的理论组合

**层级生成模型 + 局部精度加权的误差 + 策略层的主动推理 + 感知参照值控制。**

- **主动推理 / 自由能**：智能体用生成模型描述「潜在状态怎么产生观测、状态怎么转移、行动怎么改变转移」，用变分自由能 `F = E_q[ln q(s) − ln p(o,s)]` 同时做感知推断、参数学习与行动选择。*（Friston 2010, nrn2787；Parr/Pezzulo/Friston 2022）*
- **预测编码**：高层向下送预测，低层向上送「实际 − 预测」的残差。*（Rao & Ballard 1999）* 这是视觉皮层效应的功能模型，不是「所有脑区都实现同一微回路」的证据。
- **精度（precision）**：误差按它的可靠度（逆方差）加权 —— 高精度的违例才值得改上层信念，低精度噪声在底下就被门控掉。注意力/调制可以理解成对误差通道的**增益控制**。
- **控制论三件套**：反馈（误差出现后纠偏）、前馈（按扰动模型提前动手）、内部模型（forward model 预测动作的后果、inverse model 从目标反算动作）。*（Ashby 1956；Wolpert & Kawato 1998）* 而 Powers 的 PCT 说得最贴：**行为被控制的变量是「感知与参照值的差」，输出动作只是改变环境以控制感知的手段** —— 这几乎就是「行动本质是感知单元的空间移动」，但准确说法是「行动通过移动身体去改变感知」，不是「行动＝移动感知」。
- **时间尺度层级**：低层表征快波动、高层表征慢上下文，慢变量给快过程当控制参数。*（Kiebel/Daunizeau/Friston 2008）* 作者自己强调这是**待检验的假说**，不是「高层天然掌握整体信息」的证明。

## 2. 「可能传到心智，也可能不」—— 严格的说法

这是我们最想要的一条，但必须说得准：

- Rao–Ballard 原文只给了层间传递的电路图式，**没有**直接说「低层误差解决之后就不上传」。
- 安全的表述是：**未被解释的、且精度足够高的残差**才会有效地推动上层更新；被局部解释掉或被判为低精度的误差，对上层的影响可以很弱 —— 是「影响有限」，不是「信号绝对不存在」。
- 旁证来自另一条路：脊髓反射、皮层下通路、习惯回路说明行为本来就可以由短回路完成（习惯＝已学到的状态—行动映射，与依赖当前信念的目标导向策略不同）。这支持「不必每次都诉诸最高层」，但它不等于「它们都是视觉式的误差单元」。
- 心智能拿到什么：全局工作空间一路的说法是**大量并行、局部处理，少数内容竞争进一个容量有限的 workspace 再广播**（Baars；Dehaene & Changeux）。可以借它的功能区分（多数局部、少数全局、有门槛有容量），但不能宣称模型复制了意识。

## 3. 记忆：不用一条曲线，用「痕迹—激活—巩固」

- 艾宾浩斯那条曲线是真实存在的现象，但**没有唯一普适函数**：有的范式幂律拟合更好（`R(t)=A(t+c)^(−b)`），有的指数更好（`R(t)=A·e^(−λt)`）。*（Murre & Dros 2015；Wixted & Ebbesen 1991）*
- ACT-R 的写法更可算：`B_i(t)=ln Σ_k (t−t_ik)^(−d)` —— **每次提取都累加激活**，`d` 是衰减率；能不能想起来由 `P_i=σ((B_i+S_i−τ)/s)` 决定。*（Anderson & Schooler 1991）* 这条对应我们代码里的 `rehearsals`：摆到眼前一次，就记牢一档。
- 间隔效应：分散练习胜过集中重复，最佳间隔取决于想保持多久。*（Cepeda et al. 2006）*
- 巩固：突触巩固稳局部改变，系统巩固把表征随时间重组；再激活会让记忆短暂不稳定、需要再巩固。工程上可以给每条痕迹一个稳定度 `C_i ← C_i + η(1−C_i)`，有效遗忘率 `λ_i = λ_0(1−ρC_i)` —— **衰减一直存在，但巩固过的更耐久**。
- 检索诱发遗忘：练习取出一条会让同线索的竞争者更难取（抑制，不是删除）。*（Anderson, Bjork & Bjork 1994）*

## 4. 单元、模块、资源

- Minsky 的《心智社会》：心智由大量能力狭窄、各自「无心智」的 agent 互动而成。**启发性的组织思路，不是已验证的模块生成定律**；它没有给出可执行的学习规则，也没给出 agent→agency 的完整算法。*（Minsky 1986；批评见 Sowa 2003）*
- Brooks 的包容架构：并行的行为层，低层直接感知—行动并一直运行，高层抑制或替代它的输出。*（Brooks 1986）* 它的「层」是控制优先级，不是语义抽象层。
- 分层强化学习给了可算的时间抽象：option `o=(I,π,β)`、SMDP 折扣按真实时长 `k` 走 —— 高层决策自然变慢。难点也明摆着：延迟回报难归因、子目标会过时、抽象状态可能丢掉关键变量。*（Dayan & Hinton 1993；Sutton/Precup/Singh 1999）* 工程上该做的是：**在 option 结束、意外中断、价值预测明显偏差时回传一次总结误差**，而不是让顶层逐帧重决策。
- 资源分配：内感受与 allostasis 的说法是「按预测的需求预先配置资源」，而不是等偏离了再补。*（Sterling 2012；Sennesh et al. 2021）*
- **诚实边界**：「单元基于共同目标自动长出高一层模块」是产品的架构选择，不是这些理论共同证明的神经事实。真要实现，得给每种关系写清通信方向、覆盖规则与学习责任。

## 5. 可以拿去当设计准则的八条

1. 每个单元的预测对象必须明确：观测、转移、身体状态，还是别的单元的输出；误差要是**可计算**的差。
2. 误差的影响乘上它的精度/可靠度：低精度噪声就地抑制，高精度违例才跨层显著传播。
3. 层间消息是「预测向下、未解释误差向上」；**允许局部闭合，但不把「完全不上传」当成普遍脑事实**。
4. 高层按更长时间尺度编码上下文，它是**压缩摘要**，不是全知总控。
5. 「学参数 / 推断当前状态 / 选策略 / 执行行动」是四类不同操作，可以共享目标但不可混称。
6. 期望自由能要显式记两项：信息增益（认识价值）与偏好结果（实用价值/风险）。
7. 行动的定义要包含「改变感知的输入条件」：forward / inverse / 扰动 / 反馈回路分别建模。
8. 内感受与稳态目标要给优先级和情境变化；情绪是推断出来的标签，不是传感器真值。

**最该记住的一句**：FEP 那一类原则太宽，事后总能选模型、边界或先验去套 —— 真正可证伪的是「先指定生成模型、参数、学习规则和读数，再与简单控制器/强化学习基线比」。所以这些东西进产品时，一律按**可审计的有限状态版本**做，并且记下每一次预测、误差、精度、策略与参数更新。

# 三、这一版产品模型改了什么（落点）

对着上面那三条要求（层 / 机制 / 调制 / 时间，加上「单元」这一层），代码里的落点：

| 说法 | 落在哪里 | 怎么表现 |
| --- | --- | --- |
| 人是单元搭起来的 | `demo/src/units.js` 的 `UNIT_KINDS` | 十六样器官，每一样**是一群单元**：感知单元（光/声/触/温/空间/内感受）、移动单元、抓单元、记忆单元、分配单元、增益单元、预期单元、共同目标单元、选择单元… |
| 单元的共性：预测误差—行动反馈—参数调节 | 同上，每条都有 `sense`（读什么）/ `predict`（预测什么）/ `act`（能改什么）/ `param`（被调的是什么） | 界面上点「按单元看」，再点任何一群，右边就是这四问 |
| 三大反应：反馈 / 前馈 / 模型预测 | `REACTIONS` | 每一群偏哪一路，写在它的读数里 |
| 单元结成高一层模块 | `UNIT_KINDS[].organ` | 每群单元都写着「它结成的模块是〈十六样里的哪一样〉」 |
| 信息进来后可能传到心智，也可能不 | `units.js` 的 `propagate()` | **单元这一层吃不下 → 模块这一层再吃 → 还剩才递到心智**，三步都留下「接了百分之几、还剩百分之几」；界面最底下那排「传递」点一下就能看一次 |
| 每一群就地消化的胃口不一样 | `capacityOf()`（由性情维决定，`eats`） | 疑心重的人预期单元吃得少、事情更容易往上走；耐性低的人移动单元吃得多、就地就解决了 —— 同一件事换个人，停的地方就不同 |
| 心智只知道整体性的信息 | `propagate()` 的第三步 | 走到心智时记的是「〈哪一件事〉」这样一件整体的事，不是底层哪几路在响；它随后改的是注意、经历、目标、自我模型 |
| 记忆一直在淡 | `mind.js` 的 `stabilityOf/strengthOf/rehearse/faded/forgettingCurve/memoryLine` | 强度按 `exp(−年龄/稳定度)` 衰减；**摆到眼前一次就记牢一档**（抵消遗忘的间隔效应）；压缩时**先淡掉的先走** |
| 时间也在走（不是只有事件才算时间） | `mind.js` 的 `WORLD_BEAT` + `now()` | 记忆的年龄取「日志长度」与「世界节拍」里大的那个 —— 没人记事的时候，时间照样过 |
| 持续存活 | `spontaneous()` | 从他此刻的状态里挑一件最该发生的事当输入（被驳回过→越界、卡住过→没按他想的来、手里攥满→配额见底），不需要谁去调用他 |

**还没做的**：单元之间**横向**的相互影响（现在传递是「单元→模块→心智」的竖直路径）；检索诱发遗忘（抑制竞争项）；巩固度 `C` 与再巩固；把「学参数 / 推断状态 / 选策略 / 执行行动」四类操作真正分开。这些写在这里，是留给下一版的账。
