# 战国 · 风格圣经（eras/zhanguo）

依据：`docs/design/demo-spec.md` 第二节与第三节。色值的机读版在 `palette.json`，两处必须一致。
带「（起草）」的句子是整理时补的取舍，不在规格原文里，由人改定。

L1 = 程序化 2D（canvas / SVG）。更高档只换呈现层，不改这里的规则。

## 一句话

楚/齐漆画。夜是黑漆，昼是帛。不是水墨，不是皮影，不是扁平插画。

## 材质

- **漆面**：黑漆底，细颗粒噪点。
- **帛**：绢纹的底，阴影用 silkDim。
- **金银错**：细金线，云纹边饰。
- **青铜**：铜绿；铺首、铜镜（蟠螭纹镜缘）、连盏灯树；纹样用菱纹、蟠螭，作边框。
- **统一后处理**（看起来精致的最便宜来源）：所有画面过同一层——细颗粒噪点、轻微暗角、暖色光晕（加法混合）。由 `components/paint` 统一提供，没有例外。
- **字形**：说话用 Noto Serif SC（回退 Songti SC）。「旱」字与印是画出来的篆意字形（SVG/路径），不依赖字体。

## 光

- 夜里一切亮处都是暖光（灯、窗），缓慢闪烁，幅度小。
- 白昼的旱是白热的帛色；太阳是一枚朱红漆圆。
- 系统暗色时，屋里的灯更暖。深夜来访时，东郊的天是夜里的（星与荧惑）。
- 不用冷白光；夜的冷只来自 night 蓝的暗处。（起草）

## 人物

漆画式侧面剪影，比例修长：头小、衣长、袖宽。用 3–6 个贝塞尔形状拼成，关节可转（头、躯干、手臂、腿在衣下摆动）。

| 人 | 样子 |
|---|---|
| 禾 | 赭衣、短褐、发髻 |
| 田伯 | 朱衣、冠、宽袖 |
| 导师 | 漆褐深衣，坐在矮案后执笔 |
| 桑（妻） | 赭红，挽髻 |
| 小石（子） | 小，短衣 |
| 季 | 青衣、高冠、持简 |

## 构图

- **一屏一个焦点**：只有焦点明显地动；背景只有缓慢、低对比的呼吸（灯焰、热气、风里的草）。
- **地标不动**：你的座位、导师的位置、门。变化发生在地标旁边。
- **东郊是一卷横幅**：像漆奁上的出行图，从左到右依次是 家 · 田 · 井 · 社树 · 田伯家 · 路口。镜头沿横幅平移，不跑图。
- **边饰**：金线云纹与青铜纹样作边框；边框退后，不抢焦点。（起草）
- **一镜到底**：门 → 屋里 → 桌上票根 → 票根化成点 → 临淄 → 东郊显影 → 禾。中间不黑屏、不切场景、不加载。
- **没有数字、没有标签、没有按钮文字**：信息放在物件的样子里——粟瓮的高低、孩子的姿势、田缝的宽窄、灯的明暗。

## 声音

- 声音只在第一次动手（推门）之后才响。
- 全部程序化合成（Web Audio），不用音频文件。
- 音阶是五声：宫商角徵羽。灯一盏盏亮，每盏一声编钟，五声上行。音乐是编钟与埙的稀疏旋律，张力改变调式与密度。
- 环境声：夜里是蟋蟀和风；每个场景一种，交叉淡入，低电平。静默也是一种环境声。
- 音效跟着焦点：叩门是三声沉沉的木响、带回声；纸声、印声、土屑声。悬停有一点点回应，不抢戏。
- 不用现代电子音，不用连续的音乐铺底。（起草）

## 不要

- 水墨晕染、皮影、扁平矢量插画、科技感渐变。
- 百分比、计数器、进度条、仪表盘。
- 现代无衬线字体。
- 色板之外的颜色成块出现。
