# critic/golden · 参考集

这里要由**人**来放东西。参考集决定了 critic 学到的口味，所以只能由你挑；agent 不替你做，也不用自己生成的图凑数。

| 放哪 | 是什么 | 最少数量 |
|---|---|---|
| `golden/` | 你认为「有口味」的参考截图或镜头帧 | 3 件 |
| `golden/bad/` | 你不要的样子：像说明书、太满、材质跑时代 | 3 件 |
| `golden/holdout/` | 只评不看的参考 | 3–5 件 |

目前这三处都是空的。空着的时候，critic 不能运行，`bench` 也不会给出 critic 胜率。

## 怎么放

- 每件一张图（或一个文件夹放同一幕的几帧），旁边放同名的 `.md`，写两三行：它好在哪个维度（见 `../rubric.md` 的六个维度）、哪里不取。
- 文件名不要带「像某某游戏」的字样；critic 按维度问，不按出处问。
- `bad/` 里每件的 `.md` 写清是哪一种坏：说明书式、太满、材质跑时代、焦点不清……
- `holdout/` 里的东西，生成方和写代码的 agent 一律不读，不拿来调参、不拿来做图生图。

## 版权

来自商业作品的截图不要提交到公开仓库，放在本地或私有子模块里。仓库若要开源，先把这些路径加进忽略清单。

## 用来验证 bench

`bench` 能把 `golden/` 判为通过、把 `golden/bad/` 判为不通过，才算可用（管线说明 3.5）。
在参考集到位之前，bench 自己用 `bench/fixtures/` 里的一好一坏两个页面自检：`pnpm bench:selftest`。
